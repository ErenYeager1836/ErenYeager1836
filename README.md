# 🚀 Open-Source Contributions & Work

### 🎮 Valve Software & Linux Gaming Ecosystem
* **[ValveSoftware/gamescope](https://github.com/ValveSoftware/gamescope):** 
  * Fixed NV12 storage image format list configuration (`VK_IMAGE_CREATE_EXTENDED_USAGE_BIT`) for PipeWire capture on NVIDIA/Linux ([#2502](https://github.com/ValveSoftware/gamescope/pull/2502)).
  * Fixed pointer constraint regions and out-of-bounds cursor snapping in Wayland wlserver ([#2501](https://github.com/ValveSoftware/gamescope/pull/2501)).
  * Handled graceful allocation failures in Vulkan 1D/3D LUT textures ([#2499](https://github.com/ValveSoftware/gamescope/pull/2499)).
* **[ValveSoftware/Proton](https://github.com/ValveSoftware/Proton):** 
  * Safely close DLL file handles in Wine's `file_is_wine_builtin_dll` ([#10256](https://github.com/ValveSoftware/Proton/pull/10256)).
  * Driverstore path normalization for Intel graphics ([#10276](https://github.com/ValveSoftware/Proton/pull/10276)).
* **[doitsujin/dxvk](https://github.com/doitsujin/dxvk):** 
  * Handled null timeouts for D3DKMT keyed mutex acquisition under infinite waits ([#5986](https://github.com/doitsujin/dxvk/pull/5986)).
* **[ValveSoftware/openvr](https://github.com/ValveSoftware/openvr):** 
  * Added Vulkan texture array struct inheritance in codegen ([#1935](https://github.com/ValveSoftware/openvr/pull/1935)).

### 🐧 Linux Kernel & Compatibility Layers
* **Linux Kernel (LKML):** 
  * Submitted patches to driver staging and IIO subsystems.
* **[boykopovar/AnyPS5](https://github.com/boykopovar/AnyPS5):** 
  * Implemented ThreadSanitizer runtime stubs (`__tsan_acquire`, `__tsan_release`) ([#6830](https://github.com/boykopovar/AnyPS5/pull/6830)).
  * Win32 wide-environment and non-ASCII path support across AGC screenshots, guest tests, and font loaders.
  * Syscall and dialog implementations across `libSceNetCtl`, `libSceVoiceQoS`, and `libSceSaveData`.

### 🛡️ Security & Developer Tooling
